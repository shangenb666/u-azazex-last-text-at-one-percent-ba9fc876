One last text message a phone sends at one percent battery, in the dying phone's own voice:

> "Tell my charger I loved it. Tell the group chat I tried. I am going dark now, and no, I will not remember what you were about to say."

The program writes that message to `entry.txt` in the output directory.

## Run it

```sh
python3 -P -s main.py
```
